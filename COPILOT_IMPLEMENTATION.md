# VF Swiss — Frontend / UX / Content Implementation Brief for GitHub Copilot

## 0. Задача

Обновить существующий одностраничный сайт **VF Swiss** — бутиковый сервис ремонта и обслуживания швейцарских часов.

Это НЕ переписывание проекта с нуля.

Нужно сохранить существующую архитектуру и backend на Go + SQLite, существующую отправку заявок, загрузку фотографий, SMTP и текущую структуру проекта. Менять только то, что необходимо для новых требований.

Главная цель:
- сделать сайт визуально премиальным;
- перевести дизайн в тёмную luxury-эстетику;
- сделать главную страницу более живой за счёт carousel;
- улучшить форму заявки;
- добавить реальные фотографии;
- добавить popup с примерами работ;
- добавить Яндекс.Карты;
- добавить Telegram;
- добавить popup с политикой конфиденциальности;
- не сломать существующую production-логику.

# 2. Важное правило для Copilot

Перед изменением кода:

1. Изучи существующие templates.
2. Изучи существующие CSS.
3. Изучи существующий JS.
4. Изучи handlers формы заявки.
5. Изучи модели заявки.
6. Изучи SMTP service.
7. Изучи обработку upload.
8. Изучи маршруты.
9. Изучи текущий способ раздачи `/static/`.
10. Изучи существующие изображения.

После этого внеси минимально необходимые изменения.

НЕ:
- переписывать backend;
- менять SQLite без необходимости;
- менять SMTP-архитектуру;
- добавлять React/Vue/Next.js;
- добавлять npm, если существующий frontend обходится без него;
- добавлять тяжёлые frontend-фреймворки;
- удалять существующую функциональность;
- делать SPA.

Предпочтение:
- обычный HTML templates;
- CSS;
- vanilla JS;
- существующий Go backend.

# 15. Email в заявке

Email клиента НЕ является обязательным.

Поведение:

### Если email клиента не указан

Заявка:
- сохраняется в SQLite;
- письмо владельцу отправляется;
- клиентское письмо НЕ отправляется.

### Если email клиента указан

Заявка:
- сохраняется в SQLite;
- письмо владельцу отправляется;
- клиенту отправляется подтверждение получения заявки.

То есть:

```text
OWNER_EMAIL
```

получает заявку ВСЕГДА.

Email клиента:

```text
optional
```

используется только для клиентского confirmation email.

## ПОЛИТИКА КОНФИДЕНЦИАЛЬНОСТИ

**Дата публикации: 25 августа 2026 года**

Настоящая Политика конфиденциальности определяет порядок обработки и защиты персональных данных пользователей сайта VF swiss, оказывающего услуги по ремонту, техническому обслуживанию, диагностике и иным видам обслуживания часов.

Настоящая Политика распространяется на информацию, которую VF swiss может получить о посетителях сайта, клиентах и иных пользователях сайта.

### 1. Общие положения

**1.1.** Использование сайта VF swiss означает согласие пользователя с настоящей Политикой конфиденциальности в части, применимой к конкретному пользователю и способу обработки его персональных данных.
